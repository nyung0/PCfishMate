# PC FISH 보조 도구

Windows와 Python 3.13에서 실행합니다. Python 기본 라이브러리와 Windows API를 사용합니다.

```powershell
python pc_fish_helper.py
python pc_fish_helper.py --self-test
```

두 Python 파일을 같은 폴더에 둡니다. 기본 설치 경로는 `pc_fish_data.py`의 `INSTALL`에 지정돼 있습니다.

## 도감·보유 현황 및 합성

설치 파일에서 한국어 어종명과 별 등급을 읽고, 로컬 저장 파일의 보유 수량을 표시합니다. 게임이 저장한 변경 사항을 주기적으로 반영합니다. 게임 설치 파일과 저장 파일에는 읽기만 수행합니다.

- 일반 합성은 희귀도 6종과 1~5성 체크박스로 후보를 필터링하고, 재료 10마리의 예상 결과 희귀도를 계산합니다. 별 등급은 재료 선택 필터이며 결과 별 등급은 계산하지 않습니다. 일반 합성 공식은 [GamePeek의 게임 자료](https://gamepeek.wiki/pc-fish/fish)를 참고했습니다.
- 시즌 합성은 설치본에서 읽은 레시피별 필요 수량과 부족 수량을 표시합니다. 레시피가 목록에 있다는 사실은 해당 시즌이 진행 중이라는 뜻은 아닙니다.

## 자동 교배와 수조 레벨업

두 기능은 별도로 켜고 끌 수 있으며 실행할 때마다 꺼져 있습니다. **F8**로 둘 다 멈춥니다. 등록한 위치와 게임 화면이 일치할 때만 클릭하고, 교배나 레벨업 후에는 저장 파일에서 결과를 확인한 뒤 다음 동작을 진행합니다.

### 교배 후보 자동 선택

한국어 UI 1배율에서 교배 탭을 열고 다음을 한 번 등록합니다. 등록 버튼을 누르면 도구가 4초 동안 숨습니다. 그 사이 게임의 등록 위치에 마우스를 올립니다.

1. 첫째·둘째 부모 슬롯은 각각 빈 슬롯의 가운데 +에 마우스를 놓아 등록합니다.
2. 후보 목록에서 맨 위 왼쪽 카드의 정중앙을 **후보 첫 카드**로 등록합니다. 카드의 정중앙은 물고기 그림 부근입니다.
3. 사용할 희귀도·별 등급 조합마다 **후보 등급 등록**을 누르고, 활성 후보 카드 아래쪽의 희귀도 글자와 별 사이에 마우스를 놓습니다. 등록 위치는 카드 중앙에서 세로로 27픽셀 아래입니다. 교배 대기 중인 카드는 등록 대상에서 제외하세요.
4. 부모 두 마리를 선택한 상태의 활성 **교배** 버튼을 등록합니다. 결과 팝업이 열리는 경우 결과의 닫기 버튼도 등록합니다.
5. 희귀도 또는 별 등급의 오름차순·내림차순을 선택합니다. 현재 보이는 상단 4행에서 등록된 등급과 일치하는 활성 후보를 우선순위대로 선택합니다.

특정 부모 조합을 직접 정할 때는 **교배 단계 등록**으로 슬롯 열기, 후보 선택, 두 번째 슬롯 열기, 후보 선택, 교배 버튼 순서의 경로를 만들 수 있습니다. 경로 목록을 위아래로 이동해 우선순위를 변경합니다. 자동 후보 선택 설정을 갖춘 경우 해당 방식을 먼저 시도합니다.

### 자동 수조 레벨업

경험치를 채워 버튼이 활성화된 상태의 **LV↑**를 등록합니다. 다른 탭에서 수조 화면으로 자동 이동하려면 수조 탭도 등록합니다. 교배로 돌아갈 때도 교배 탭 등록이 필요합니다. 게임 저장의 경험치가 설치본의 다음 레벨 기준에 도달하면, 등록된 버튼이 보일 때 클릭합니다.

화면 위치, DPI, 게임 UI 배율을 변경하면 다시 등록해야 할 수 있습니다. 스크롤 아래 후보의 탐색과 실제 게임에서 끝까지 교배·레벨업을 수행하는 실기 검증은 남아 있습니다. 버튼 위치와 화면 표본은 `%LOCALAPPDATA%\PCFishHelper\settings.json`에 로컬로 저장됩니다.
