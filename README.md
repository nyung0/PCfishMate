# PCfishMate

**[최신 Windows 릴리스 다운로드](https://github.com/nyung0/PCfishMate/releases/latest)**

Windows와 Python 3.13에서 실행합니다. Python 기본 라이브러리와 Windows API를 사용합니다.

```powershell
python pc_fish_helper.py
python pc_fish_helper.py --self-test
```

두 Python 파일을 같은 폴더에 둡니다. 기본 설치 경로는 `pc_fish_data.py`의 `INSTALL`에 지정돼 있습니다.

## 도감과 시즌 합성 재료

설치 파일에서 한국어 어종명과 별 등급을 읽고, 로컬 저장 파일의 보유 수량을 표시합니다. 게임이 저장한 변경 사항을 주기적으로 반영합니다. 게임 설치 파일과 저장 파일에는 읽기만 수행합니다.

- 도감은 실제 게임 이미지를 카드로 표시합니다. 이름, 희귀도→별 등급, 별 등급→희귀도, 남은 교배 횟수 순으로 정렬할 수 있습니다. 남은 교배는 같은 어종·등급으로 묶인 보유 개체의 횟수를 합산합니다.
- 시즌 합성 재료는 필요한 물고기 한 마리당 카드 하나를 표시합니다. 보유 재료는 컬러, 부족한 재료는 흑백입니다. 레시피 목록은 게임 설치본에서 읽습니다.
- 소스에서 실행할 때는 두 Python 파일 옆에 `fish_sprites` 폴더를 둡니다. EXE에는 이미지가 포함되어 있습니다.

### 도감에서 일반 합성 재료 추가

한국어 게임 UI 1배율에서 일반 합성 화면과 왼쪽 물고기 선택 창을 엽니다. 두 창의 위치를 유지합니다.

1. 도감의 **후보 목록 제목 등록**을 누르고 게임 왼쪽 창의 **물고기 선택** 제목 중앙에 마우스를 놓습니다.
2. 재료 슬롯을 비운 상태에서 **첫 빈 슬롯 등록**을 누르고 오른쪽 슬롯의 맨 왼쪽 위 **+** 중앙에 마우스를 놓습니다.
3. **후보 카드 등록**을 체크하고 보조 도구에서 원하는 도감 카드를 클릭합니다. 게임에서 같은 어종·희귀도·별 등급의 잠금·사용중 표시가 없는 후보를 찾고, 물고기 그림 중앙에 마우스를 놓습니다. 보낼 물고기 종류마다 한 번 등록합니다.
4. 후보가 목록에 보이는 상태에서 보조 도구의 도감 카드를 클릭하면 게임에 재료 한 마리를 추가하고 빈 슬롯이 하나 줄었는지 확인합니다. 목록을 스크롤해 원하는 후보를 표시할 수 있습니다. 최종 합성은 게임에서 직접 누릅니다.

## 자동 교배와 수조 레벨업

자동화 탭에서 실행할 기능을 체크한 뒤 **자동화 시작**을 누릅니다. **중지** 또는 **F8**로 둘 다 멈춥니다. 등록한 위치와 게임 화면이 일치할 때만 클릭하고, 교배나 레벨업 후에는 저장 파일에서 결과를 확인한 뒤 다음 동작을 진행합니다.

### 교배 후보 자동 선택

한국어 UI 1배율에서 게임의 교배 탭을 열고 앞에 둡니다. **자동 교배**와 **교배 허용 희귀도**를 체크한 후 **자동화 시작**을 누릅니다. 보조 도구가 빈 부모 슬롯과 후보 목록을 찾아 부모 두 마리를 고르고 교배 버튼을 누릅니다.

후보 우선순위는 현재 화면에서 희귀도 높은 순, 같은 희귀도에서 별 등급 높은 순입니다. 기본과 일반 1성의 화면 표본이 내장돼 있으며, 이전 버전에서 저장한 후보 등급 표본도 사용할 수 있습니다. 다른 후보 표본과 교배 결과 팝업의 자동 닫기는 실제 게임 확인이 필요합니다.

하트가 한 개 이상이면 교배를 시도합니다. 교배 버튼 클릭 후 다음 시도까지 기본 10초를 기다립니다. **교배 간격 (초)**에서 1~3600초로 바꿀 수 있습니다.
### 자동 수조 레벨업

경험치를 채워 버튼이 활성화된 상태의 **LV↑**를 등록합니다. 다른 탭에서 수조 화면으로 자동 이동하려면 수조 탭도 등록합니다. 교배로 돌아갈 때도 교배 탭 등록이 필요합니다. 게임 저장의 경험치가 설치본의 다음 레벨 기준에 도달하면, 등록된 버튼이 보일 때 클릭합니다.

화면 위치, DPI, 게임 UI 배율을 변경하면 다시 등록해야 할 수 있습니다. 실제 게임에서 스크롤 탐색과 교배·레벨업을 끝까지 수행하는 검증은 남아 있습니다. 버튼 위치와 화면 표본은 `%LOCALAPPDATA%\PCFishHelper\settings.json`에 로컬로 저장됩니다.


## 내부 교배 자동화

Windows EXE의 첫 실행에서 설치를 마치면 컨트롤러가 열립니다. 실행 중에도 교배 허용 희귀도를 변경할 수 있고, 교배와 수조 레벨업의 시간별 기록을 볼 수 있습니다. [내부 플러그인과 컨트롤러](internal/README.md)

게임 스프라이트는 설치본에서 추출합니다. 소스 실행 전 `python -m pip install UnityPy`와 `python extract_sprites.py`를 실행하세요.
