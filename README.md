# PC FISH 보조 도구

Windows에서 Python 3.13으로 실행합니다. Python 설치에 포함된 Tkinter와 Windows API를 사용합니다.

```powershell
python pc_fish_helper.py
python pc_fish_helper.py --self-test
```

## 도감과 합성 계산기

도감에서 어종 이름, 희귀도, 별 등급, 보유 수량을 입력합니다. 같은 어종·희귀도·별 등급을 저장하면 수량이 갱신됩니다. 수량이 0이면 미보유로 기록할 수 있습니다. 게임에서 가져오는 기능은 아직 없습니다.

합성 탭의 체크박스로 재료 후보를 좁히고 보유 수량 범위에서 10마리를 선택합니다. 일반 합성의 결과 희귀도 확률을 계산합니다. 별 등급은 후보 필터에 쓰며 결과 별 등급, 시즌 레시피, 개체의 잠금과 교배 대기 상태는 계산하지 않습니다. 일반 합성 공식은 [GamePeek의 이전 게임 빌드 자료](https://gamepeek.wiki/pc-fish/fish)를 참고했으며 설치된 빌드에서 실제 합성 결과는 검증하지 않았습니다.

## 자동화 미리보기

자동 교배와 수조 레벨업은 처음에 꺼져 있습니다. 게임 UI 배율과 화면 위치를 고정한 뒤, 자동화 탭의 안내에 따라 버튼을 등록하세요.

- 교배 경로 하나는 부모 슬롯 열기, 후보 선택, 두 번째 부모 슬롯 열기, 후보 선택, 교배 버튼 순으로 등록합니다. 경로를 위아래로 옮겨 우선순위를 정할 수 있습니다. 첫 단계의 화면과 일치하는 경로 중 맨 위 경로를 시도합니다. 부모 조합을 희귀도나 별 등급으로 실시간 판별하는 기능은 아직 없습니다.
- 레벨업 버튼은 게임에서 레벨업 가능 상태일 때 등록합니다. 수조 탭이 열린 상태에서 버튼과 화면 위치가 일치할 때 클릭을 시도합니다.
- 자동화는 한 번의 교배 또는 레벨업 입력을 시도한 뒤 꺼집니다. 게임 결과를 확인한 다음 다시 켜세요. 예상 화면이 4초 안에 나타나지 않으면 중지합니다. F8로도 중지할 수 있습니다.
- 버튼 모양이 변하거나 게임 위치가 바뀌면 버튼을 다시 등록해야 할 수 있습니다. 실제 게임에서 교배 및 레벨업 성공은 아직 검증되지 않았습니다.

보유 기록과 등록 설정은 로컬의 `%LOCALAPPDATA%\PCFishHelper\settings.json`에 저장됩니다.
