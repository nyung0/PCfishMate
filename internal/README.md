# PCfishMate 설치 및 내부 모듈

PC FISH Windows x64 IL2CPP용 BepInEx 플러그인입니다. 게임의 메인 스레드에서 현재 하트와 물고기 목록을 읽고, 게임의 `UIBreed.SetParent`와 `UIBreed.Breed`를 호출합니다. 게임이 결과를 반영하면 다음 주기를 기다립니다.

## 설치 및 사용


PCfishMate는 비공식 도구입니다. [Steam 이용 약관 제4조](https://store.steampowered.com/subscriber_agreement/#4)는 Steam 콘텐츠와의 자동화된 상호작용을 금지하며, 위반 시 계정이나 구독이 제한될 수 있습니다. 설치 안내를 확인하는 절차로 Valve나 게임사의 사용 허가가 생기지는 않습니다.

설치 프로그램은 선택한 게임 폴더에 BepInEx와 모듈을 설치하거나 갱신하고, 필요한 경우 로더 설정과 Unity 캐시를 변경합니다. 자동 합성은 조건에 맞는 물고기를 재료로 소비할 수 있습니다. 도감은 게임 설치 파일과 저장 데이터를 로컬에서 읽고, 즐겨찾기·설정·자동화 기록은 이 PC에 보관합니다.

Windows 팝업과 작업표시줄 깜박임은 상단 톱니바퀴의 **알림 설정**에서 각각 켤 수 있습니다. 앱은 GitHub에서 새 버전을 확인하며, 새 버전이 있을 때 현재 버전 옆에 **업데이트** 버튼을 표시합니다. **업데이트**를 누르면 다운로드 후 앱이 자동으로 재시작합니다. 게임 모듈을 갱신해야 할 때는 게임 종료 안내가 표시됩니다.


**PCfishMate.exe**에 로더와 플러그인이 포함되어 있습니다.

1. PC FISH를 종료하고 EXE를 실행합니다.
2. 초기 설정 창에서 자동 감지된 Steam 게임 폴더를 확인하거나 **폴더 선택**으로 변경합니다. 설치 내용을 읽고 동의한 뒤 **설치 및 실행**을 누릅니다.
3. 설치가 완료되면 컨트롤러가 열립니다. 이후에는 저장된 폴더와 모듈을 확인한 뒤 바로 실행합니다. 이미 설치에 동의한 PC에서는 새 모듈을 자동으로 갱신합니다.
4. **게임 실행**을 누르고 연결이 표시되면 필요한 자동화와 허용 희귀도를 선택한 뒤 시작합니다.

교배에는 체크된 희귀도의 개체만 부모로 사용합니다. 실행 중 체크를 바꾸면 다음 교배부터 적용되며, 체크가 하나도 없으면 교배만 대기합니다. 수조 자동화는 별도로 동작합니다. 자동화 기록은 현지 시간으로 교배 완료, 확인된 수조 레벨 변경, 시작·중지·오류를 보여줍니다. 상세 게임 로그는 **로그 보기**에서 열 수 있습니다.

**같은 희귀도끼리만 교배**를 켜면 현재 우선순위에서 같은 희귀도의 부모 두 마리가 있는 첫 조합을 고릅니다. 예를 들어 희귀가 한 마리이고 고급이 두 마리면 고급 두 마리를 고릅니다.

**합성 자동화**는 조건에 맞는 재료 10마리가 모이면 일반 합성 탭을 열고 별 등급을 자동으로 선택합니다. **합성 옵션**에서 자동 등록 조건 네 가지와 일반~신화 희귀도 다섯 가지를 지정하면 즉시 적용됩니다. **교배·합성 간격 (초)**은 교배와 합성에 적용됩니다. 초기값은 모두 켜짐이며, 시즌 재료 제외는 설치본에 들어 있는 시즌 레시피를 기준으로 합니다. **같은 별 등급 10마리만 합성**과 **같은 희귀도 10마리만 합성**은 별도로 설정할 수 있습니다. 별 등급 제한을 끄면 여러 별 등급의 재료를 후보에 포함합니다. 게임에서 조합을 거절하면 자동으로 채운 슬롯을 비우고 합성을 진행하지 않습니다. 잠긴 물고기와 교배 대기 중인 물고기는 제외합니다.

자동화 기록에는 교배 완료와 합성 완료가 표시됩니다. 합성 완료에는 사용한 재료의 별 등급과 희귀도별 수량이 표시됩니다.

도감에서 이름으로 검색하고, **색상 합쳐 보기**를 켜면 이름·희귀도·별 등급이 같은 카드를 묶어 볼 수 있습니다. 자동화 탭의 하트는 현재 보유량과 다음 회복까지의 시간을 표시합니다.

**색상** 탭에서 물고기와 별 등급, 색상을 선택하세요. 기존 색 계열 전체를 바꾸거나 브러시와 페인트통으로 직접 칠할 수 있습니다. 마우스 휠로 확대·축소하고, Space를 누른 채 드래그하면 그림을 이동할 수 있습니다. `Ctrl+Z`와 `Ctrl+Y`로 되돌리기와 다시 실행을 합니다. **선택 완료 · 미리보기**에서 편집 결과를 확인한 후 **게임에 적용**하거나 게임의 **원본 복원**을 선택할 수 있습니다.

직접 그리기에서 그림판에 포커스가 있으면 `B`로 브러시, `G`로 페인트통, `I`로 스포이드, `H`로 손 도구를 선택합니다. `Alt`를 누른 채 픽셀을 클릭하면 선택한 도구를 유지하면서 색을 가져옵니다. 브러시를 선택하면 마우스 위치에 칠할 픽셀의 윤곽이 표시됩니다.

PCfishMate 창을 닫으면 컨트롤러에서 시작한 자동화가 중지되고 앱이 종료됩니다.

### 수동 설치

1. [BepInEx IL2CPP 설치 안내](https://docs.bepinex.dev/master/articles/user_guide/installation/unity_il2cpp.html)에 따라 PC FISH 설치 폴더에 BepInEx 6 Windows x64 IL2CPP를 설치합니다. 현재 게임에서는 메타데이터 버전 31을 지원하는 6.0.0-be.793으로 검증했습니다.
2. `PCFishInternal.dll`을 게임 설치 폴더 아래 `BepInEx/plugins`에 복사한 뒤 게임을 시작합니다.
3. 컨트롤러 `PCfishMate.exe`를 실행합니다. 허용 희귀도와 간격을 정한 후 **자동화 시작**을 누릅니다. 기본 간격은 10초입니다.
4. 컨트롤러의 **중지**나 **F8**로 정지합니다. 컨트롤러를 닫거나 연결이 끊기면 컨트롤러에서 시작한 자동화는 중지됩니다.

남은 교배 횟수가 있는 개체와 횟수 제한이 없는 기본 개체를 대상으로, 잠금·쿨다운 상태를 제외한 뒤 희귀도와 별 등급이 높은 순으로 고릅니다. 두 부모의 개체 ID는 서로 달라야 합니다.

실제 게임에서 컨트롤러와 동일한 연결을 사용해 교배 탭 자동 열기, 연속 교배 2회와 중지를 검증했습니다.

## 소스 빌드


배포본을 만들기 전에 번들에 포함되는 [BepInEx와 구성요소](https://github.com/BepInEx/BepInEx), Unity 기본 라이브러리 ZIP, [FMOD DLL](https://www.fmod.com/legal)의 재배포 조건과 고지 의무를 확인합니다. 배포 이미지와 아이콘에 게임 리소스를 사용했다면 해당 이미지의 사용 권한도 확인합니다. 설치 화면의 사용자 확인과 각 구성요소의 재배포 권한은 별개입니다.


저장소 루트의 [빌드 안내](../README.md#main을-클론한-경우)를 따라 Windows 실행 파일을 만들 수 있습니다.

시즌합성 탭은 현재 시즌의 물고기를 희귀도 낮은 순으로 표시합니다. 물고기와 별 등급을 선택하면 재료 보유량을 확인할 수 있으며, 남은 교배 0회인 물고기만 계산할 수도 있습니다. 시즌 번호와 종료 시각은 게임 모듈에서 읽어 한국시간으로 표시합니다.

기존 설치 동의가 있으면 모듈을 자동 갱신합니다. 업데이트에 게임 종료가 필요하면 정상 종료를 요청하고 완료 후 Steam으로 다시 실행합니다. Windows 관리자 권한 확인이 표시될 수 있습니다.
